## 1. 마크업 (MenuPanel.tsx)

`row.id === "rewards"` 일 때만, 라벨 칸을 보상함 전용으로 그리세요. `points` 줄을 따로 그리는 것과 같은 방식이면 됩니다.

- `.menu-row-label` 은 `overflow: hidden` 이라, 금화·말풍선·반짝이를 **라벨 태그 안에 넣지 마세요.** 잘립니다.
- 예: `.menu-rewards-copy` 안에 (1) `.menu-row-label` 「보상함」 (2) `.menu-toss-hint`(금화 + 반짝이 + 말풍선).
- 오른쪽 메타(냥코인 잔액, `formatMeta`)와 아이콘의 빨간 점, 줄 클릭으로 보상함 시트가 열리는 동작은 그대로 두세요.
- 문구는 `menu.json` 의 `rows.rewards.tossHint` 에서 읽고, 값이 없으면 코드 기본값도 `"토스로 보내기"` 로 두세요. `MenuRowDef` 에 `tossHint?: string` 을 추가하면 됩니다.
- 말풍선은 장식이므로 줄 버튼의 접근성 이름을 가리지 않게 `aria-hidden="true"` 로 두거나, 줄 전체에 `aria-label` 을 「보상함, 토스로 보내기」처럼 한 번만 분명하게 주세요. 스크린 리더에 같은 말이 두 번 나오면 안 됩니다.

## 2. 생김새 · 크기 (시안 04 그대로, CSS px)

색은 기존 메뉴를 따르세요. `--menu-amber: #ffc48a`, 크림 말풍선은 `.menu-paw-tip` 과 같이 배경 `#fff6e6`, 글자 `#2a2238`.

| 요소 | 크기 |
|---|---|
| 냥코인 금화 | **18×18px**. `ncoinIcon(18)`, `width/height={18}` |
| 라벨과 금화 사이 | 약 6px |
| 금화와 말풍선 사이 | **6px** |
| 말풍선 | 높이 **18px**, 내용 너비(지금 문구 기준 약 **64px**), `padding: 0 6px`, `border-radius: 8px`, `border: 1.5px solid #ffc48a`, 배경 `#fff6e6`, 글자 `#2a2238` |
| 글자 | 9px, weight 700, letter-spacing -0.03em, line-height 15.5px. 메뉴와 같이 `"Noto Sans KR"` |
| 꼬리 | 6×6px, 말풍선과 같은 크림+주황 테두리, **왼쪽**을 가리켜 금화에 붙음 |
| 반짝이 | 금화 근처 작은 4각 별 2개(약 7px, 4px), 색 `#fff6e6` / `#ffd9a0`. 글자를 가리지 마세요 |
| 그림자 | 금화에 옅은 금빛 `drop-shadow`, 말풍선 `box-shadow: 0 3px 10px rgba(6, 5, 16, 0.36)` |

금화는 줄 안에서 라벨과 세로 가운데로 맞추세요. 말풍선도 금화와 세로 가운데입니다.

`.menu-scroll` 은 `overflow-x: hidden` 입니다. 반짝이나 그림자가 가로로 잘리지 않게, 장식은 줄 안에 머물게 하세요.

## 3. 움직임

- 메뉴가 열릴 때(`.menu-root.is-open`) 말풍선이 살짝 작았다가 커지며 나타납니다(약 0.86 → 1, fade, 200–280ms). 기존 줄 등장(`.menu-row` 의 `menu-row-in`, 줄마다 30ms 지연)과 어색하게 겹치지 않게 맞추세요.
- 금화는 약 **1.4초** 주기로 위아래 **2–3px** 톡톡 움직입니다(`ease-in-out`, 메뉴가 열린 동안 반복).
- 반짝이는 천천히 투명도·크기가 바뀌며 깜빡입니다. 두 개면 박자를 조금 어긋나게 하세요.
- `@media (prefers-reduced-motion: reduce)` 와 기존 `.menu-root.is-reduce` 에서는 **움직임 없이** 최종 모습만 보여 주세요. 금화·말풍선·문구는 그대로 보입니다.
- CSS 애니메이션만 쓰세요. 새 라이브러리를 넣지 마세요.

## 4. 공간이 좁을 때 (숨기지 마세요)

말풍선은 **항상** 보입니다. `display: none`, 조건부 렌더, 로컬 저장, “이미 봄” 플래그로 끄지 마세요.

오른쪽 메타가 길어지거나(예: 도감 보상 숫자가 붙은 전체 메타) 화면이 약 **360px** 너비여도, 글자가 잘리거나 줄 밖으로 나가면 안 됩니다. 패널은 `width: 312px; max-width: 100%` 입니다.

우선순위:

1. 「보상함」 라벨은 줄이지 말고 한 줄로 유지하세요.
2. 한 줄에 들어가면 시안 크기(금화 18px, 말풍선 9px)를 유지하세요.
3. 공간이 부족하면 말풍선 글자와 좌우 여백만 **조금** 줄이세요(글자는 8px보다 작아지면 안 됩니다). 그래도 부족하면 말풍선 안에서만 두 줄로 접으세요(예: 「토스로」 / 「보내기」). 문구 자체는 그대로입니다.
4. 메타(`.menu-row-meta`)는 지금처럼 `max-width: 118px` 말줄임을 유지해도 됩니다. 말풍선을 없애서 메타를 살리지 마세요.
5. 치브론과 아이콘은 가리지 마세요.

360px 너비(패널이 거의 꽉 찬 상태)에서 「보상함」·금화·「토스로 보내기」 전체가 보이고, 잘리지 않는지 확인하세요.
