# 방꾸미기 개선 5가지 기획 메모 (2026-11-22)

- 시안: 같은 폴더의 `A-cozy.png`, `B-auto.png`, `C-favorite.png`, `D-mood.png`, `E-today.png`
- 기준 화면: room-bigger 적용 후 모습(보기 모드는 한 줄 제목, 꾸미기 모드는 한 줄 서랍)
- 360×756 폰 화면, 눈오는 겨울 오두막 방에 가구를 놓은 상태로 그렸어요.
- 화면 문구는 모두 "발바닥 젤리"로 써요. 포인트·출금·인출·토스포인트·P는 쓰지 않아요.

| 기능 | 서버 필요 | 난이도 |
|---|---|---|
| A COZY 레벨 선물 | **필요** (wallet 함수 + jelly_rules 추가) | 보통 |
| B 추천 배치 | 필요 없음 | 쉬움~보통 |
| C 고양이 최애 가구 | 애정도를 주면 **조금 필요**, 연출만이면 필요 없음 | 보통 (그림 작업 있음) |
| D 방 소리·밝기 | 필요 없음 | 쉬움 (소리 파일 준비) |
| E 오늘의 가구 | **필요** (할인 가격을 서버가 알아야 함) | 보통 |

추천 순서: **B → D → A → E → C**. B·D는 서버가 없어서 바로 할 수 있어요. A·E는 wallet을 한 번에 같이 고치면 배포가 한 번으로 끝나요. C는 그림 작업이 가장 많아요.

## A. COZY 레벨 선물 (`A-cozy.png`)

**지금 문제:** COZY 레벨은 방 3개를 여는 데만 쓰여요. Lv.10이 넘으면 올라도 받는 게 없어요.

**규칙 제안**

| 항목 | 제안 값 |
|---|---|
| 매 레벨 선물 (Lv.11부터) | 발바닥 젤리 **50** |
| 5레벨마다 (Lv.15·20·25·30…) | **COZY 한정 소품 1개 + 젤리 50** (그 레벨의 젤리 50과 별도) |
| 한정 소품 | Lv.15 / 20 / 25 / 30 / 35 / 40 / 45 = 7개. 처음엔 3개(15·20·25)만 만들고 나머지는 나중에 추가해요 |
| 받는 곳 | 레벨이 오르면 **편지함**에 편지가 와요. 30일 안에 받으면 돼요 (지금 편지함 규칙 그대로) |
| 레벨 계산 | 지금 공식 그대로예요. 가진 아이템 점수로 계산하고, Lv.10 다음부터는 80점마다 1레벨이에요 |

- 얼마나 받을 수 있나: 모든 아이템을 1개씩 가지면 약 Lv.25예요. 같은 가구를 최대 개수까지 다 사면 약 Lv.48이에요.
  - Lv.25까지: 젤리 750 + 한정 소품 3개
  - Lv.48까지: 젤리 약 1,900 + 소품 7개
- 비용과 비교하면: 80점(1레벨)을 모으려면 보통 가구 8개, 젤리 약 2,000~2,500개를 써요. 선물 50은 쓴 젤리의 약 2%라서, 젤리가 넘쳐 경제가 망가지지 않아요.

**이미 레벨이 높은 사람(예: Lv.23) 소급 지급**
- 업데이트 후 처음 접속할 때 서버가 레벨을 계산해요.
- Lv.11~지금 레벨까지의 선물을 **편지 1통**에 모아 보내요. 예: Lv.23이면 젤리 650 + 한정 소품 2개(Lv.15·20).
- 받은 레벨은 서버에 "여기까지 받음"으로 저장해요. 그다음부터는 새 레벨만 편지로 와요.
- 한 번에 받는 소급 젤리에 상한을 둬요. 제안: **1,000**.

**어뷰징 방지**
- **가구를 놓았다 빼기 반복은 문제가 안 돼요.** 지금 공식이 "놓았는지"가 아니라 "가졌는지"로 계산하고, 되팔기도 없어서 점수가 올라가지 않아요.
- 진짜 위험은 **폰이 레벨을 거짓으로 보내는 것**이에요. 그래서 선물 레벨은 **서버가 직접 계산**해요.
  - 계산에 쓰는 것: 서버 젤리 기록에 남은 `room:` 구매, `roomUnlock` 방 열기 선물, 서버가 준 출석·애정도 아이템, 기본 아이템
  - 쓰지 않는 것: 폰이 보내는 owned 목록
- 같은 레벨 선물은 계정당 1번만 줘요(`cozyLv:<레벨>` 보상 ID로 중복을 막아요).
- 서버 젤리 이전 전에 폰에서만 산 아이템은 서버 기록에 없어서 레벨이 낮게 계산될 수 있어요. 아래 "정해 주세요"를 봐 주세요.

**서버 필요:** 있어요.
- wallet에 `cozy_claim` 동작 추가 (서버가 레벨 계산 → 편지함에 편지 넣기)
- `jelly_rules`에 `cozyRewards`(레벨별 젤리, 5레벨 소품 ID) 추가
- 한정 소품 3개는 `itemPrices`에 넣지 않는 지급 전용 아이템이에요(출석 한정과 같은 방식)

**정해 주세요**
1. 매 레벨 젤리: **50**? (30~80 사이 추천)
2. 5레벨 한정 소품 3개의 테마. 제안: 오로라 스노우글로브 / 별빛 냥이 쿠션 / 황금 냥이 액자. 그림은 새로 그려야 해요(시안의 스노우글로브는 기존 그림을 임시로 쓴 거예요).
3. 소급 상한: **1,000** 젤리?
4. 서버 기록에 없는 예전 구매를 인정할지. 인정하면 폰이 보낸 목록을 **1번만**, 상한을 두고 받아요(젤리 이전 `migrateCap` 방식과 같아요). 인정하지 않으면 서버 기록만 써요.

## B. 추천 배치 (`B-auto.png`)

**규칙 제안**
- 꾸미기 모드 왼쪽 위에 **✨ 추천 배치** 버튼을 둬요.
- 누르면 **지금 방에서 가진 가구만** 써서 자동으로 놓아요. 다른 방에 놓인 가구는 빼지 않아요(서랍에 남은 것만 써요).
- 놓는 순서: 큰 가구 → 고양이가 앉는 가구 → 작은 가구·소품 → 러그 → 벽 꾸미기
- 방마다 미리 정한 **자리표**(방 4개 × 추천 자리 16~20칸)를 따라요.
  - 예: 겨울 오두막은 벽난로를 오른쪽 벽 가운데에, 트리를 왼쪽 앞 구석에 둬요.
  - 칸에 맞지 않으면 가까운 빈칸에 둬요. 문과 고양이 다니는 길로 가운데 2×2는 비워 둬요.
- 그 방 테마 가구를 먼저 쓰고, 칸이 남으면 다른 테마 가구도 써요.
- 끝나면 아래에 「가진 가구 15개로 꾸며 봤어요 · **되돌리기**」 안내가 떠요.
  - 되돌리기는 누르기 바로 전 상태로 **한 번에** 돌아가요.
  - **완료를 눌러야 저장**돼요. 취소하면 원래대로예요.
- 가구가 3개보다 적으면 「가구가 더 있으면 추천해 드릴게요」와 상점 바로가기를 보여 줘요.

**서버 필요:** 없어요. 폰 안에서만 해요.

**정해 주세요**
1. 다른 테마 가구도 섞을지 (제안: 섞되, 그 방 테마를 먼저)
2. 누를 때마다 조금씩 다른 배치(자리표 2~3개 중 랜덤)로 할지, 항상 같은 배치로 할지

- 최애 가구가 방에 있으면 그 고양이가 그 가구로 갈 확률이 **4배**예요(지금 최애냥 하트 침대 `seatWeightMul 4`와 같아요).
- 최애 가구에 오르면 **특별 연출**이 나와요.
  - 행복 자세
  - 하트·반짝이
  - 말풍선(품종마다 2줄씩, 예: 「여기 최고다냥…♡」 「이 자리 내 거야」)
- **처음 발견할 때 한 번** 「최애 가구 발견」 카드를 보여 줘요. 카드에는 치비 고양이 그림이 들어가고, 도감 고양이 페이지에 "최애 가구: ○○" 기록이 생겨요.
- 아직 못 찾은 품종은 「?」로 보여 줘서 찾고 싶게 만들어요. 힌트는 "따뜻한 곳을 좋아해요"처럼 한 줄이에요.
- **그림(망곰이처럼 표정이 풍부한 치비 스타일):** 품종마다 "최애 자세" 그림 1장을 추가해요.
  - 카드용 큰 그림 23장 + 방 스프라이트 프레임 1개씩
  - 시안의 치즈냥 그림이 예시예요(눈을 웃는 모양으로 감고, 볼 홍조, 담요를 꼭 안은 모습).
  - 처음엔 기존 happy 프레임 + 하트로 하고, 그림은 품종별로 조금씩 늘려도 돼요.

**애정도와 연결 (제안: 연결)**
- 최애 가구에 오르면 그 고양이의 **애정도 +5, 하루 1번**이에요(새 출처 `favSeat`). 애정도 하루 상한 75는 그대로예요.
- 최애냥의 하트 쿠션 침대 규칙은 그대로 둬요. 최애냥은 하트 침대와 자기 최애 가구 둘 다 좋아해요.

**서버 필요**
- 연출만 하면 없어요.
- 애정도를 주면 조금 필요해요. 지금 애정도는 저장 데이터에 같이 저장되고 서버 저장본과 합쳐지니까, `favSeat` 출처를 허용 목록과 하루 횟수 검사에 추가해요.

**정해 주세요**
1. 위 품종별 최애 가구 표를 그대로 쓸지, 바꿀지
2. 애정도 연결 여부와 크기 (제안: +5, 하루 1번)
3. 품종별 새 그림을 한 번에 다 만들지(23장), 인기 품종 5~6개부터 할지

## D. 방 소리·밝기 (`D-mood.png`)

**규칙 제안**
- 오른쪽 위 **🕯 분위기** 버튼(지금 "그림자 켜짐" 자리)을 누르면 작은 창이 떠요. 그림자, 밝기, 방 소리를 한곳에서 바꿔요.
- **밝기 3단계**
  - 밝게: 방을 조금 밝게, +10%
  - 보통: 지금 모습
  - 아늑하게: 방을 20% 어둡게 하고 램프 11종 불빛을 1.5배로
  - 방마다 따로 폰에 저장해요. 지금 아침·낮·노을·밤 변화 위에 겹쳐요.
- **방 소리 (환경음)**
  - 달밤 침실: 귀뚜라미 + 시계 째깍
  - 고양이 카페: 카페 웅성임 + 컵 소리
  - 벚꽃 온실: 새소리 + 살랑 바람
  - 겨울 오두막: 벽난로 타닥 + 창밖 바람
  - 볼륨 0.15~0.25, 30~60초 반복, 파일 하나에 300KB 이하(ogg + m4a)예요.
- **기본은 꺼짐이에요.** 배경음악(BGM)은 지금처럼 기본 꺼짐이고 설정에서 켜요.
  - 방 소리는 이 창에서 따로 켜는 스위치이고, 처음엔 꺼져 있어요.
  - 광고 중이거나 앱이 가려지면 꺼지는 규칙은 BGM과 같아요.
- **CC0 소리 후보 (출처 표기 필요 없음)**
  - Freesound에서 라이선스를 "Creative Commons 0"으로 걸러서 검색: `fireplace crackle`, `cafe ambience`, `crickets night`, `birds garden`, `wind window`
  - OpenGameArt의 CC0 환경음
  - 파일마다 라이선스가 CC0인지 꼭 확인해요. 다운로드할 때 URL을 `docs/sounds-license.md`에 적어 둬요.
  - Pixabay 소리는 자체 라이선스(CC0 아님)라서 피해요.

**서버 필요:** 없어요.

**정해 주세요**
1. 방 소리를 이 창에서 따로 켤지(제안), 아니면 BGM 설정을 따라갈지
2. 밝기 이름: 「밝게 · 보통 · 아늑하게」로 할지
3. 방별 소리 4가지 조합이 괜찮은지

## E. 오늘의 가구 (`E-today.png`)

**규칙 제안**
- 꾸미기 서랍 첫 탭에 **오늘의 가구**를 둬요. 매일 **한국 시간 밤 12시**에 바뀌어요.
- **3개를 할인해요.** 2개는 **20%**, 1개는 **30% 특가**이고, 가격은 10 단위로 내림해요.
  - 예: 컵 캣타워 650 → 520
  - 예: 냥이 해먹 600 → 420 (특가)
- 고르는 규칙
  - **아직 안 가진** 상점 아이템 중에서 골라요.
  - 출석 한정·애정도 선물·COZY 한정은 빼요.
  - 3개 중 1개는 큰 가구(특가 자리), 2개는 가구/소품/벽 꾸미기예요.
  - 열린 방 테마를 먼저 골라요. 벽지·바닥은 빼요(한 번 사면 무제한이라).
- **광고 보고 다시 고르기는 하루 1번**이에요(짧은 보상형 광고). 다시 고르면 3개가 모두 바뀌고, 할인율은 같아요.
- 각 할인 아이템은 그날 **1개만** 할인가로 사요. 2개째부터는 정가예요.
- **배너 광고:** 오늘의 가구 탭 아래에 배너 1개를 둬요. 도감 등에서 쓰는 **같은 광고 그룹**(`economy.json` → `ads.banner`에 새 키 `roomDeal`, 같은 adGroupId)을 써요. 꾸미기 탭들에는 배너를 넣지 않아요.

**서버 필요:** 있어요. 지금 서버는 `itemPrices`의 정가만 받아요(다른 값이면 거절해요). 그래서:
- wallet이 **오늘의 3개를 직접 정해요**. 계정 + 날짜 + 다시 고른 횟수로 정해서, 폰이 바꿀 수 없어요.
- 앱은 서버에 목록을 물어봐요(`deal_list`).
- 할인 구매는 새 보상 ID `roomDeal:<itemId>:<날짜>:<구매ID>`로 해요. 서버가 그날 목록에 있는지, 이미 할인으로 샀는지 확인하고 할인가를 빼요.
- 다시 고르기는 `deal_refresh`(하루 1번)예요. 광고 시청은 서버가 확인할 수 없어서, 횟수만 서버가 막아요.
