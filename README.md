# 오늘의 행운

날짜마다 달라지는 하루 운세를 토스 디자인 시스템으로 보여주는 앱인토스 미니앱이에요.

- 오늘 행운 지수와 연애·금전·직장·건강 운세
- 행운의 색, 숫자, 시간, 음식, 아이템
- 열어본 운세 기록과 공유하기

같은 날짜는 항상 같은 결과가 나와요. 운세는 재미로 보는 콘텐츠예요.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 미리볼 수 있어요. 토스 앱 안에서는 앱인토스 샌드박스 또는 `.ait` 번들로 실행해요.

## 배포하기

앱인토스 배포 API 키는 [앱인토스 콘솔](https://apps-in-toss.toss.im/) > 워크스페이스 > API 키에서 발급받을 수 있어요.

```bash
npm run build
npm run deploy
```
