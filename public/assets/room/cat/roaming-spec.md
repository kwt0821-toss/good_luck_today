# 방꾸미기 — 돌아다니는 고양이 (cat-roam 1.0)

## 에셋
- `cat-sprite.png` + `cat-sprite.json`: 24프레임(174×137 world px, 3x), 공통 발 앵커 `(87,132)` = 하단 중앙. 모든 프레임이 같은 앵커라 전환해도 흔들리지 않아요.
- `frames/*.png`: 같은 프레임의 개별 PNG(투명, 반짝이·하트 포함).
- `cat-shadow.png` (120×44, 앵커 60,22): 고양이 발 앵커 바로 아래에 먼저 그려요. 모든 포즈·품종 공용.
- 크기: 몸통 ≈125 px ≈ 0.8타일. 스케일 없이 1:1로 그려요(화면 배율은 방 전체 배율을 따라감).

## 방향 (iso)
| 애니메이션 | 이동 | 프레임 |
|---|---|---|
| walk_dl | +row (왼쪽 아래) | 원본 1행 |
| walk_ul | −col (왼쪽 위) | 원본 2행 |
| walk_dr | +col (오른쪽 아래) | walk_dl 좌우 반전 |
| walk_ur | −row (오른쪽 위) | walk_ul 좌우 반전 |
걷기 8 fps, 4프레임 루프. 포즈: idle_sit, groom, loaf, sleep(루프 유지), stretch 900ms, happy 700ms, tapped 600ms, yawn 900ms(1회).

## 규칙
1. **방당 1마리**(도감에서 고른 고양이). 위치는 타일 (c,r), 화면 좌표 = P(c+0.5, r+0.5), P(c,r) = (1920+(c−r)·78, 900+(c+r)·39).
2. **이동 가능 타일**: `rooms.json`의 `walkableTiles`가 있으면 사용하고, 없으면 8×8에서 가구 footprint(바닥 러그·벽 아이템 제외)를 뺀 칸. 편집 후 다시 계산해요.
3. **길찾기**: A*, 4방향 iso 이웃(±c, ±r), 비용 1, 휴리스틱 맨해튼. 경로 없으면 그 자리에서 idle.
4. **속도**: 1타일 / 0.6 s, 타일 사이 선형 보간. 방향 바뀔 때 해당 walk 애니메이션으로 즉시 전환.
5. **깊이 정렬**: 가구와 함께 정렬, 고양이 키 = (현재 타일 c + r, c − r). 이동 중에는 목적지 타일 기준(앞쪽으로 갈 때 가구에 묻히지 않게). 그림자는 바닥 그림자 레이어에.
6. **행동 루프**: 랜덤 빈 타일로 걷기 → 도착 후 2–6 s idle(idle_sit / groom / loaf / stretch / yawn 중 랜덤) → 약 20% 확률로 sleep 10–20 s → 반복.
7. **탭**: 고양이 히트박스(프레임 불투명 영역) 탭 → 걷기 중단 → tapped 600ms → happy 700ms → 1 s 후 루프 재개. 잠잘 때 탭해도 같은 순서로 깨요.
8. **편집 모드**: 고양이를 숨겨요(또는 현재 프레임으로 정지하고 반투명 50%). 편집 종료 시 이동 가능 타일을 다시 계산하고, 고양이가 막힌 칸에 있으면 가장 가까운 빈 칸으로 옮겨요.
9. 히어로 캣(캣베드 위 고정 고양이)과는 별개예요.
