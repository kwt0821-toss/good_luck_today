# 튜토리얼 스펙 (tutorial-1.5)

운영 설정 `config/tutorial.json` / `public/config/tutorial.json`과 동일 버전.  
진행 표시: **STEP n/5** (step 3→3/5, step 4→4/5, step 5→5/5).

## Step 3 — 도감 (screen: `dex`) · STEP 3/5

### 3-1 슬롯 이동·하이라이트
- 뽑은 카드 탭 자동 선택.
- `#dex-slot-{cardId}`를 400ms center scroll. 스크롤 중 터치 잠금.
- 펄스 + **「방금 만난 고양이가 여기 들어왔어요」** + `[다음]`
- 동작 줄이기 ON: instant scroll, 펄스 생략.

### 3-2 코인 수령
- `#dex-claim-{cardId}` + 손가락. **「코인을 톡 누르면 보상을 받아요」**
- 보상 줄: 냥코인 아이콘 **x 1**, 발바닥 포인트 아이콘 **x 20**

### 3-3 수령 후
- 버스트 + 토스트 **「냥코인 1개 + 20포인트 받았어요」** → **「냥코인을 처음 받았어요!」** `[알겠어요]` → step 4.

## Step 4 — 방꾸미기 (screen: `room`) · STEP 4/5

### 4-1 집어 들기
- `#drawer-item-0`만 강조. 오버레이는 타깃만 뚫고, 타깃은 z-index > overlay + `touch-action: none`.
- 꾹 250ms 또는 바로 드래그. 집는 동안 서랍 스크롤 잠금.
- **「서랍에서 마음에 드는 아이템을 꾸욱 눌러 보세요」**

### 4-2 드래그·배치
- 고스트 팔로우, suggestTile 초록 점선, 드래그 힌트.
- 불가 칸 → 빨강 + 서랍 복귀 + **「여기는 자리가 없어요」**

### 4-3 배치 완료
- place FX → **「잘했어요! 다른 아이템도 자유롭게 꾸며 보세요」** `[다음]`

### 4-4 발바닥 포인트
- `#room-points-chip` 강조 + 손가락. **칩 외 영역 음영 + 클릭 차단**.
- 문구 속 「발바닥 포인트」에 아이콘 인라인.
- **「발바닥 포인트를 모아 원하는 아이템을 구매할 수 있어요!」** `[완료]` → **step 5** (아직 tutorialDone 아님).

## Step 5 — 보상함 안내 (screen: `main`) · STEP 5/5

### 5-1 메뉴
- 메인 복귀, `#icon-menu` 강조 + 손가락. 문구는 버튼 **아래**. **나머지 음영 + 클릭 차단**(메뉴만 탭 가능).
- **「메뉴에서 모은 냥코인을 확인할 수 있어요」** (냥코인 아이콘 인라인)

### 5-2 보상함 행
- `#menu-row-rewards` 강조. **나머지 음영 + 클릭 차단**(보상함 행만 탭 가능).
- **「보상함을 눌러 보세요」**

### 5-3 출금 안내
- `#withdraw-picker` / `#wallet-card` 강조.
- **「냥코인 10개부터 토스포인트로 바꿀 수 있어요」** + 작은 글씨 **「※ 하루 최대 50원」**
- 잔액 < 10: 출금 버튼 비활성 + **「조금만 더 모으면 받을 수 있어요」**
- `[알겠어요]` → `tutorialDone=true`, `tut.rewardsIntro=seen`
