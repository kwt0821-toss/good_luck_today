# 카드 프레임 v5 — frames-v5
v4와 같은 구조·layout.json. 바뀐 파일: frame-basic-1, frame-basic-2 (+@2x), 새 window-1star, window-2star (+@2x). window-basic은 삭제. 3★·4★·5★·밈·캐릭터·레전드는 v4 그대로.
- **1★ 밀크티**: 밀크티 크림색 레일 + 발바닥 모서리, 상단 하트 크레스트 + 반짝이, 별 1개, 얇은 갈색 금 테두리 창. 창 배경 window-1star(크림→밀크티 그라데이션 + 흰 하트 무늬 + 반짝이). 글자색: 한 줄 #5A4030, 이름 #7A5236.
- **2★ 코튼 블루**: 하늘색 레일 + 은색 테두리 창, 상단 둥근 사파이어 크레스트, 별 2개, 창 모서리 작은 사파이어 4개, 레일 흰 점 무늬. 창 배경 window-2star(하늘 그라데이션 + 물방울 점 + 아래 구름). 글자색: 한 줄 #26466E, 이름 #2F5E9E.
- 계단: 1★(하트·테두리 얇음) < 2★(은 테두리·보석 4개·무늬) < 3★(피치, 글로우·진주 줄·보석 크레스트). 1★·2★는 foil 없음.
