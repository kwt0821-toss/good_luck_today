# 업적·칭호 UI 스펙 v2 (achievements-1.1)
데이터는 ops-config/achievements.json(20개)을 써요. 배지 파일은 public/assets/achv/badges/{id}.svg(viewBox 64×64)예요.
**v1과 달라진 점: 메뉴의 '업적' 행을 없앴어요.** 이제 칭호 리본을 눌러서 들어가요. 메뉴 아이콘 빨간 점도 업적 때문에는 켜지 않아요(보상함 조건만 남아요).

## 이름 변경 (1.1)
- first_legend 전설을 본 냥 → **전설을 본 냥이**
- att_7 매일 오는 냥 → **맨날 보고프냥**
- att_100 백일 동거냥 → **백일이냥**

## 배지
- 분류별 테두리 모양과 색은 그대로예요. 수집 민트 원, 뽑기 앰버 별, 출석 하늘 방패, 방꾸미기 핑크 집, 교환 라벤더 육각형.
- 20개 모두 그림이 달라요. 아래 점은 같은 계열 안에서의 단계 표시예요. 40pt에서도 알아볼 수 있어요(badges-board.png).
- 상태별 표시: 받음 = 원래 색 / 받을 수 있음 = 민트 글로우 + 빨간 점 / 진행 중(그리드) = grayscale 100% + 투명도 .45, 이름은 보여 줘요 / 상세 화면에서 진행 중 = grayscale .75

## 진입: 칭호 리본 (achv-main-ribbon)
- `#title-ribbon`: 높이 24짜리 민트 알약 모양이에요. 순서는 배지 16pt + 칭호 + ›. 누르면 칭호 시트가 열려요.
- 메인: CAT. 로고 아래, 부제 줄 위(left 24, top 257). 방: MY ROOM. 아래(left 24, top 192).
- 받을 칭호가 있으면 리본 오른쪽 위에 빨간 점(9pt)이 떠요. 메인과 방 둘 다예요.
- 칭호가 없으면 점선으로 된 빈 리본 "칭호 없음 · **새내기 집사** 받기 ›"을 보여 줘요. 리본을 숨기지 않아요(입구가 이것뿐이라서요).

## 칭호 시트 `#sheet-title`
1. **그리드** (achv-sheet-1-grid): 바텀시트(높이 660, 크림색)예요.
   - 헤더: "칭호" + "달고 있는 칭호 · {칭호} · 받을 보상 n개" + 작은 링(n/20)
   - 탭: 전체 · 수집 · 뽑기 · 출석 · 방꾸미기 · 교환. 받을 칭호가 있는 탭에 빨간 점이 떠요.
   - 4열 칸(높이 86) `#title-tile-{id}`: 배지 40 + 한 줄 칭호(말줄임). 받을 수 있으면 민트 글로우 + 빨간 점, 달고 있는 칭호에는 '장착' 꼬리표.
   - 정렬은 data 순서를 따라요(계열 단계 순서).
2. **상세** (achv-sheet-2 진행 중 / achv-sheet-3 받을 수 있음): 칸을 누르면 같은 시트 안에서 상세로 바뀌어요("‹ 칭호 목록"을 누르면 돌아가요).
   - 배지 112 (받을 수 있으면 광선 + 글로우), 상태 칩(진행 중 / 달성! 보상을 받을 수 있어요 / 얻은 칭호), 칭호(Gamja 30), "분류 · 업적 이름 (조건)"
   - 진행 카드: 진행바(10pt) + n/목표. 단계 계열이면 **단계 그래프**를 같이 보여 줘요. 노드에는 목표 숫자와 칭호를 달고, 달성한 노드는 ✓, 지금 보는 노드는 크게 + 링, 채움선은 현재 값까지예요. "단계 · 지금 {값}{단위}"
     - 계열: 도감 1/10/30/60/90 · 뽑기 50/300/1000 · 출석 7/30/100 · 배치 10/30 · 방 해금 2/전부 · 교환 20/100. 한 번에 끝나는 업적(5★, 레전드, 첫 세트)은 진행바만 있어요.
   - 보상 알약: 냥코인, P
   - 버튼(하단 고정, 높이 54): 받을 수 있음 → **[보상 받기]**(민트) `#btn-achv-claim-{id}` / 받음 → **[달기]**(네이비, 이미 달고 있으면 "달고 있어요" 비활성) / 진행 중 → 비활성 "진행 중 · {남은 수}{단위} 남았어요"
3. **받기 축하** (achv-sheet-4-claimed): [보상 받기]를 누르면 냥 알림 축하 시트가 떠요(배지 132, NEW TITLE, 칭호 알약, 보상). 버튼은 [닫기] [칭호 달기]. 효과음은 sfx-reward-coin. 닫으면 상세로 돌아가요(버튼은 [달기]로 바뀌어요).

## 알림
업적을 달성한 순간에는 냥 알림 reward 스낵바를 띄워요. "새 칭호 **{칭호}**을 얻었어요 · 칭호 리본에서 받기" [받기]. [받기]를 누르면 그 칭호의 상세가 열려요. 여러 개면 "새 칭호 {n}개를 얻었어요"로 합쳐요.

## 메뉴 스펙 변경
- 메뉴 패널의 **'업적' 행을 지워요**(`#menu-row-achv` 삭제). 보상함 행 아래에는 아무것도 넣지 않아요.
- 메뉴 아이콘 빨간 점 조건에서 '받을 업적'을 빼요. 업적 알림은 리본 점만 써요.

## API
- `GET /achievements` → [{id, progress, goal, state: locked|claimable|claimed}], equippedTitleId, claimableCount
- `POST /achievements/claim {ids:[...]|'all', requestId}` → 지급 결과 + 잔액. 업적 id별로 계정당 한 번이고, 진행도는 서버 카운터 기준이에요.
- `POST /profile/title {achievementId|null}` → 받은 업적만 달 수 있어요
