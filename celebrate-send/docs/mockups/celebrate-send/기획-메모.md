# 냥코인 받기 축하 창 — 시안 메모 (프롬프트 아님)

배경 화면은 실제 앱(로컬 실행) 보상함을 찍은 것이고, 창만 새로 그렸어요.

## 지금 코드에 있는 결과 상태 (MenuPanel.tsx doWithdraw)
- done(완료) → 지금은 위쪽 초록 알림 "50원을 받았어요" + 시트 안 "받았어요"
- pending(확인 중: 서버 sending/unknown/manual_review) → 파란 알림 "확인 중이에요"
- testGrant(테스트 지급) → 알림만
- failed(실패, 냥코인 돌려줌) → 빨간 알림 + [다시 시도]
- DAILY_LIMIT(오늘 한도 50원) → 지금은 알림 없음

## 시안
1. 01 버튼 누르면 "보내는 중…"으로 바뀌고 잠김
2. 02 완료: 가운데 축하 창 — "냥코인 50개를 / 토스로 보냈어요!", "토스 앱에서 바로 확인할 수 있어요", 알약 "냥코인 50개 → 50원", "남은 냥코인 70개 · 오늘은 다 보냈어요", [확인]. 위쪽 초록 알림은 빼서 한 번만 보여요.
3. 03 확인 중: 차분한 창 — "토스로 보내는 중이에요", "토스에서 확인하고 있어요. 조금만 기다려 주세요.", 안내 "확인이 끝나면 지급 내역에 '완료'로 바뀌어요. 버튼을 다시 누르지 않아도 돼요.", [확인] + "지급 내역 보기"
4. 04 창을 닫은 뒤 보상함 안 문구도 같은 말로
5. 05 실패/한도는 창 없이 알림만: "보내지 못해 냥코인을 돌려드렸어요"(기존 유지), 새로 "하루에 보낼 수 있는 한도(50원)에 도달했어요 · 내일 0시에 다시 보낼 수 있어요"

테스트 지급은 지금처럼 알림만, 축하 창 없음.
