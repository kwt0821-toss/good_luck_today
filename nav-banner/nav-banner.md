# Cursor 프롬프트 — 하단 탭 · 편지 아이콘 · 도감 배너 (행운냥)

아래 전체를 Cursor에 붙여 넣으세요. **앱 코드와, zip에 들어 있는 그림 파일만** 바꾸세요. 서버(표·wallet 함수)·새 환경 변수·새 패키지·유료 서비스는 만들지 마세요.

규칙:
- 뒤로가기 버튼(`DevBackButton` 등)을 새로 만들지 마세요. 창은 바깥 탭·기존 닫기(X)·기기 뒤로가기로 닫습니다.
- `appName`은 `lucky-cat` 그대로 유지하세요.
- 화면 문구에 **포인트 / 토스포인트 / 출금 / 인출 / "P"** 를 쓰지 마세요. 재화 이름은 **발바닥 젤리**(짧게 **젤리**)와 **냥코인**입니다.
- **메인 화면 가운데 대표 그림은 건드리지 마세요.** `public/assets/main/mainscreen-assets/`(잠자는 고양이, 침, 꼬리 등), `card-facedown.png`, `moon-glow.png`, `bg-night-base.webp` 와, 이를 심고 움직이는 `HomeScreen.tsx` / `App.css` 의 고양이·덱 마크업과 애니메이션을 수정하지 마세요. 곧 따로 교체할 예정입니다. 이번 작업은 오른쪽 위 편지 아이콘, 하단 탭, 도감 배너, 방꾸미기 하단 여백만 합니다.
- 오른쪽 위 편지·메뉴 버튼의 자리와, 이미 적용된 편지 버튼 투명 스타일(크림 네모 배경 없음, 28×28 아이콘, 빨간 점)은 유지하세요. 메뉴 버튼은 건드리지 마세요.

**다른 프롬프트와 파일이 겹칠 수 있습니다.** 편지함·주간 미션·방 구경 가기·보상함 동작을 되돌리거나 덮어쓰지 마세요. 이번 작업에서 손대는 화면에 이미 있는 기능은 그대로 두고, 아래 세 가지만 더하거나 바꾸세요.

## 2. 메인 · 도감 · 방꾸미기 공통 하단 탭

세 화면에 **같은 하단 탭**을 두세요. 칸은 왼쪽부터 **도감 / 홈 / 방꾸미기** 세 개입니다. 시안 02·03·04처럼 가로로 고르게 나누고, 지금 있는 화면은 크림색 아이콘·글씨에 짧은 호박색 밑줄을 넣어 표시하세요. 나머지 칸은 `--cream-dim` 으로 흐리게 하세요. 아이콘 28×28, 글씨 11px, 기존 `.main-nav-btn` / `.main-footer` 느낌을 유지하세요.

아이콘:
- 도감: 이미 있는 `/assets/main/icon-dex-book.svg`
- 홈: zip의 `/assets/main/icon-home.svg` (고양이 귀 상자 + 달 + 분홍 반짝임. 메인 화면 밤하늘을 떠올리도록 그렸습니다. 방꾸미기 집 아이콘과 구별됩니다)
- 방꾸미기: 이미 있는 `/assets/main/icon-room-house.svg`

권장: `src/components/AppTabBar.tsx`(이름 비슷해도 됨)로 한 곳에서 그리고, 세 화면에서 재사용하세요. 같은 마크업을 세 번 복사하지 마세요.

동작:
- 도감 → `collection` 화면. 방꾸미기 → `room` 화면. 홈 → `home` 화면.
- **이미 그 화면에 있으면** 다시 열어 화면을 새로 만들지 마세요. 홈에 있을 때 홈을 눌러도 뽑기 상태가 리셋되면 안 됩니다.
- 도감 버튼은 반드시 `id="icon-dex"` 를 유지하세요. 튜토리얼 `config/tutorial.json` 이 `#icon-dex` 를 가리킵니다. `dexBadge` 가 있으면 지금까지처럼 아이콘 오른쪽 위에 빨간 점을 보여 주세요.
- `src/App.tsx` 에서 도감·방꾸미기 화면에 홈/도감/방꾸미기로 가는 콜백을 넘겨 주세요. `CollectionScreen` / `DexScreen` / `RoomScreen` 의 기존 `onBack` 은 기기 뒤로가기 등 이미 있는 닫기 흐름용입니다. **화면에 뒤로가기 버튼을 새로 그리지 마세요.**
- 튜토리얼이 진행 중이면 하단 탭으로 다른 화면에 나가지 못하게 하세요. `#icon-dex` 를 눌러 도감으로 가는 기존 튜토리얼 발걸음은 그대로 동작해야 합니다.
- 오른쪽 위 편지·메뉴와 겹치면 안 됩니다. 탭은 화면 **맨 아래**에만 두세요.
- 이 탭을 **넣지 않을 화면**: 확률 안내, 카드 공개(reveal), 편지함 시트, 메뉴 시트, 방 구경 목록·방문 화면, 그 밖에 잠깐 덮는 전체 화면. 카드 상세 시트·메뉴가 열렸을 때는 시트가 탭보다 위에 있어야 합니다(탭이 시트를 뚫고 나오지 않게).

`src/screens/HomeScreen.tsx` 의 기존 `.main-footer`(도감·방꾸미기 두 칸, `justify-content: space-between`)를 이 세 칸 탭으로 바꾸세요. 메인 화면의 고양이와 카드 덱, 뽑기 버튼, 지갑 칩, 편지·메뉴는 그대로 두세요.

도감은 `src/screens/DexScreen.tsx` / `DexScreen.css`(또는 `CollectionScreen.tsx` 가 감싼 자리) 맨 아래에 같은 탭을 두세요. 목록 스크롤은 탭에 가리지 않게, `.dex-body` 아래 여백과 `.dex-fade` 가 예전의 맨 아래 배너가 아니라 **새 탭 높이**를 비우게 하세요. `.dex-screen` 의 하단 패딩도 탭과 맞춰 주세요.

## 3. 도감 맨 아래 배너 제거, 목록 4줄마다 배너

지금 `src/screens/DexScreen.tsx` 는 카드 상세가 닫혀 있을 때 화면 맨 아래에 `<BannerAdSlot placement="dex" />` 를 두고, `src/components/BannerAdSlot.css` 의 `.dex-screen > .banner-ad-slot` 규칙이 배너를 화면 하단에 붙입니다.

1. 그 **맨 아래 배너를 빼세요.** 위 CSS(화면 너비로 늘리고 하단 패딩을 상쇄하던 규칙)도 더 이상 쓰이지 않으면 정리하세요.
2. 대신 도감 **카드 목록 사이**에 4줄마다 배너를 하나씩 넣으세요. `placement` 는 지금과 같이 `"dex"` 입니다. 광고 그룹은 `public/config/economy.json` 의 `ads.banner.dex.adGroupId` 를 그대로 쓰세요. 새 그룹 ID를 만들지 마세요. 보상함·출석 등 다른 자리의 배너는 건드리지 마세요.
3. 「4줄」은 **지금 보이는 탭의 카드 줄**입니다.
   - 고양이(품종) 탭: `.dex-breed-row` 네 개마다 한 줄. 지금 품종이 18개라 4·8·12·16번째 줄 다음에 들어갑니다. 세트 완성 보상 띠(`dex-set-claim-banner`, 도감 전체 완성 포함)는 줄로 세지 마세요.
   - 스페셜·시즌·캐릭터 탭: 3열이므로 카드 12장(화면 4줄)마다.
   - 레전드 탭: 2열이므로 카드 8장(화면 4줄)마다.
   - 그리드에 배너를 한 칸으로 끼워 넣지 마세요. 4줄 덩어리 사이에 가로로 꽉 찬 슬롯을 두세요.
4. 그 탭에 줄이 4줄이 안 되면 배너를 넣지 마세요. 짧은 탭 맨 아래에 예전처럼 배너를 다시 붙이지 마세요.
5. 테스트 광고 ID `ait-ad-test-banner-id` 는 **개발 모드에서만** 쓰세요. 이미 `src/lib/tossBanner.ts` 의 `bannerAdGroupId` 가 `import.meta.env.DEV` 일 때만 테스트 ID를 돌려 줍니다. 이 분기를 없애거나, 실제 빌드에 테스트 ID가 들어가게 바꾸지 마세요. 운영에서는 `economy.json` 의 그룹 ID만 쓰세요.
6. `BannerAdSlot` 의 기존 약속은 지키세요. 호스트 안은 비워 두고, 지원되지 않거나 `onNoFill` / `onAdFailedToRender` 이면 자리를 접고, 광고를 타이머로 새로고침하지 말고, 언마운트 때 `destroy()` 하세요. 목록 속 배너용으로 스타일만 나누면 됩니다(예: 목록 여백, 위아래 간격). 시안의 「광고」 글씨 자리표시는 **시안용**입니다. 실제 슬롯 위에 앱이 「광고」 라벨을 따로 그리지 마세요. SDK 소재에 이미 있습니다.

**스크롤이 느려지면 안 됩니다.** 품종이 늘어 배너가 많아져도, 목록을 손가락으로 내릴 때 버벅이면 안 됩니다.

- 화면에 보이거나 곧 보일 슬롯에만 `TossAds.attachBanner` 하세요. `IntersectionObserver` 를 쓰고, root 는 도감 스크롤 영역(`.dex-body`)으로 하세요.
- 화면에서 멀리 떠난 슬롯은 `destroy()` 하되, 한 번 로드되어 펼쳐진 높이는 남겨 두어 스크롤이 위아래로 뛰지 않게 하세요.
- 동시에 붙어 있는 배너 인스턴스는 적게 유지하세요(근처에 보이는 2~3개 정도).
- 스크롤 때마다 매 프레임 attach/destroy 하지 마세요.
- 탭을 바꾸면 이전 탭 배너는 모두 `destroy()` 하세요.
- 카드 상세 시트가 열렸을 때 배너가 시트 위로 올라오면 안 됩니다.

## 4. 방꾸미기 — 아이템 서랍과 하단 바가 탭 위에

`src/screens/RoomScreen.tsx` / `RoomScreen.css` 보기 모드 맨 아래에 같은 하단 탭을 두세요. 탭은 화면 맨 아래, 그 **위에** 기존 조작이 앉아야 합니다.

지금 아래쪽은 화면 바닥에 붙어 있습니다.

- `.lucky-bar` : `bottom: max(18px, env(safe-area-inset-bottom, 18px))`
- `.lucky-visit-btn`, `.lucky-photo-btn`, `.lucky-hint` : 그 바 위(`+ 96px`)
- `.lucky-drawer` : `bottom: 0`, 높이 420 / 펼침 560 / 튜토리얼 300
- `.lucky-paint-dock` 의 `bottom: 428px` / `568px` / `308px` (서랍 높이 + 8)

탭 높이만큼 이 값들을 올리세요. CSS 변수(예: `--app-tabbar-height`)로 탭·서랍·바·독이 같은 숫자를 쓰게 하면 좋습니다. 아이템 서랍이 탭을 가리거나, 탭이 서랍 손잡이·아이템을 가리면 안 됩니다. 시안 03처럼 보기 모드에서는 「꾸미기」 바와 하단 탭 사이에 여백이 있어야 합니다.

방 구경 목록·방문 화면에는 이 탭을 넣지 마세요. 닫으면 내 방꾸미기로 돌아오는 지금 흐름을 유지하세요.

## 확인

- 메인 화면 편지 아이콘에 분홍 깃발이 없고, 우체통만 보이며, 안 받은 편지가 있으면 빨간 점이 예전과 같이 뜹니다. 편지함은 그대로 열립니다.
- 메인·도감·방꾸미기 하단에 도감 / 홈 / 방꾸미기 세 칸이 있고, 지금 화면만 크림색+호박색 밑줄로 표시됩니다. 시안 02·03·04 와 같습니다.
- 메인 화면 가운데 잠자는 고양이와 카드 덱, 뽑기 버튼, 편지·메뉴 자리는 바꾸기 전과 같습니다.
- 도감 맨 아래에 배너가 없고, 고양이 탭에서는 품종 4줄마다 배너가 있습니다. 줄이 4줄보다 짧은 탭에는 배너가 없습니다.
- 도감 목록을 빠르게 내려도 버벅임이 없고, 탭을 여러 번 바꿔도 배너가 두 개 겹치거나 빈칸이 길게 남지 않습니다.
- 개발 모드에서만 테스트 광고가 붙고, 실제 빌드에서는 `economy.json` 의 도감 광고 그룹을 씁니다.
- 방꾸미기에서 꾸미기 바·사진 찍기·방 구경 가기·아이템 서랍이 하단 탭 위에 있고, 서랍을 펼쳐도 탭이 가려지지 않습니다.
- 튜토리얼의 `#icon-dex` 발걸음이 동작하고, 화면에 뒤로가기 버튼이 새로 생기지 않았습니다.

작업이 끝나면 main 브랜치에 머지해 줘.
