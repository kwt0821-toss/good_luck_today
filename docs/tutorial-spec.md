# 튜토리얼 스펙 (tutorial-1.5)

운영 설정 `config/tutorial.json` / `public/config/tutorial.json`과 동일 버전.  
진행 표시: step 3은 **STEP 3/4**, step 4는 **STEP 4/4**.

## Step 3 — 도감 (screen: `dex`)

### 3-1 슬롯 이동·하이라이트
- 뽑은 카드 탭(품종/스페셜/캐릭터/레전드) 자동 선택.
- `#dex-slot-{cardId}`를 `scrollIntoView({ block: "center", behavior: "smooth" })`로 **400ms** 스크롤. 스크롤 중 터치 잠금.
- 스크롤 후 펄스(scale 1→1.06→1, 400ms)와 말풍선  
  **「방금 만난 고양이가 여기 들어왔어요 · {품종} · {등급}」** + `[다음]`, 건너뛰기.
- 동작 줄이기 ON: `behavior: "auto"`, 펄스 생략.

### 3-2 코인 수령 안내
- 스포트라이트 `#dex-claim-{cardId}` + 손가락 탭 힌트.
- 말풍선: **「코인을 톡 누르면 보상을 받아요 · 냥코인 1 + 20P」**
- 코인 배지만 탭 가능 (`POST /dex/rewards/claim`).

### 3-3 수령 후
- 코인 버스트 + `sfx-reward-coin`.
- 토스트: **「냥코인 1개 + 20포인트 받았어요」**
- 이어서 냥코인 첫 안내 말풍선 **「냥코인을 처음 받았어요!」** + `[알겠어요]` → step 4.

## Step 4 — 방꾸미기 (screen: `room`)

`suggestTile`: `{ c: 5, r: 2 }`. 대상 아이템: `#drawer-item-0` (방석 등 서랍 첫 NEW).

### 4-1 집어 들기
- `#drawer-item-0`만 강조.
- **꾹 250ms** 또는 **바로 드래그**로 집기.
- 말풍선: **「서랍에서 마음에 드는 아이템을 꾸욱 눌러 보세요」**
- 강조 아이템만 이동 가능. 건너뛰기 표시.

### 4-2 드래그·배치
- 반투명 고스트가 손가락을 따라감.
- 바닥 격자 + suggestTile 초록 점선 칸 + 서랍→칸 드래그 힌트 루프.
- 빈칸이면 어디든 배치 가능. 불가 칸은 빨강 → 서랍으로 되돌리며 토스트 **「여기는 자리가 없어요」**.
- 강조 아이템만 이동. 건너뛰기 표시.
- 동작 줄이기 ON: 힌트 루프 대신 고정 화살표.

### 4-3 배치 완료
- `item-place` SFX + **240ms** 바운스 + 반짝이.
- 말풍선: **「잘했어요! 다른 아이템도 자유롭게 꾸며 보세요」** + `[완료]` → `tutorialDone=true`.
- 동작 줄이기 ON: 바운스 대신 고정 표시.
