# 메인 화면 대표 그림 B안 — 풀어 넣는 방법

이 zip을 **저장소 맨 위 폴더**(`package.json`이 있는 곳)에서 푸세요. 파일이 제자리로 들어갑니다.

## 풀리면 생기는 파일

- `main-hero-b.md` — Cursor에 붙여 넣는 프롬프트
- 앱에 넣는 그림(`public/assets/main/mainscreen-assets/`):
  - `hero-b-idle.webp` — 평소 모습(달 위 고양이, 카드, 꼬리)
  - `hero-b-blink.webp` — 같은 그림, 눈만 감은 것
  - `hero-b-blink-overlay.webp` — 눈 부분만 있는 투명 레이어
  - `hero-b-empty.webp` — 오늘 카드를 다 뽑았을 때(빈 손)
  - `hero-b-sparkle.webp` — 반짝이는 작은 별
  - `hero-b-layout.json` — 카드·눈·별의 자리와 권장 크기
- 시안(참고용, **앱 빌드에 넣지 않음**): `docs/mockups/main-hero-b/`
  - `01-home.png` — 평소 메인 화면
  - `02-empty.png` — 오늘 카드를 다 뽑은 화면

시안은 참고용이에요. 서버 작업은 이 zip에 없어요. 기존 잠자는 고양이 그림 파일은 덮어쓰지 않습니다. 풀어 넣은 다음 `main-hero-b.md` 를 Cursor에 붙여 넣으면 됩니다.

하단 세 칸 탭(도감 / 홈 / 방꾸미기)은 이 zip과 별개입니다. 이미 적용되어 있으면 그대로 두고, 아직이면 `nav-banner` 작업을 따로 해 주세요.
