# 냥코인·포인트 얻는 법 (help-1.0)
- **열기**: 보상함 지갑 카드 오른쪽 위 `?` 버튼, 메뉴 › 냥코인·포인트 얻는 법. 바텀시트(top 96px, 둥근 모서리 28px, 크림 #FFF6E6, 뒤는 밤하늘 + 45% dim).
- **탭**: 냥코인 / 발바닥 포인트 (세그먼트, 선택 시 navy #1E1A2B). `?`를 누른 위치에 따라 첫 탭을 정해요(지갑의 냥코인 쪽 → 냥코인, 포인트 쪽 → 포인트).
- **구성**: 헤더 카드(navy, 아이콘 44px + 한 줄 설명) → '쓰는 곳' 박스(navy 테두리) → 섹션별 흰 카드 목록(제목·짧은 설명 / 오른쪽 금액 칩 + 한도). 목록만 스크롤, 헤더·탭 고정.
- **금액 칩**: 냥코인 = 민트(#DDF6EC / #1F7158) + `public/assets/ncoin/` 아이콘, 포인트 = 앰버(#FFE9D2 / #9A4F17) + `icon-paw-coin.svg`, 16px.
- **문구 데이터**: `help.json`. `help_gen.py`가 economy.json·achievements.json에서 금액을 읽어 만들어요. 경제 값이 바뀌면 다시 실행(또는 앱에서 같은 로직으로 런타임 생성).
- **냥코인 탭**: 광고 뽑기 +1(하루 4), 포인트 광고 +1(하루 10), 출석 7일째 +5(광고 10 + 뽑기권), 새 고양이 +1~50, 세트 +10, 도감 완성 +100, 칭호 +1~(총 81). 쓰는 곳: 10냥코인부터 10개 단위로 토스포인트, 하루 최대 50원.
- **포인트 탭**: 포인트 광고 +10P(하루 10, 주말 2배), 출석 +10~100P(7일째 광고 200P), 새 고양이 +20P, 중복 카드 +10~150P, 세트 +200~300P, 도감 완성 +3000P, 칭호 +20P~(총 2820P). 쓰는 곳: 확률업 뽑기권 200P(하루 2장, 최대 3장), 방꾸미기 아이템, 새 방 1,500P~.
