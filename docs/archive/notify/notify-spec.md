# 냥 알림 (Nyang Notify) v1 — LuckyCat 알림 시스템
2026-10-14 · 기존 토스트(작고 어두운 텍스트 바)는 모두 이 시스템으로 바꿔요.

## 1. 단계 (언제 무엇을 쓰나)
| 단계 | 컴포넌트 | 쓰는 때 | 사라짐 |
|---|---|---|---|
| T1 | **냥 스낵바** (`.ny-snack`) | 행동 결과, 보상, 가벼운 안내 | 2.6초 (액션 버튼이 있으면 4초). 위로 스와이프하거나 탭하면 닫혀요 |
| T1+ | **축하 배너** (`.ny-celebrate`) | 보상이 2개 이상 한꺼번에 생겼을 때 (세트 완성, 출석 7일) | 3.2초, 고양이가 함께 나와요 |
| T2 | **인라인 경고 칩** (`.ny-chip`) | 지금 할 수 없는 이유 (대상 바로 옆) | 원인이 해결되거나 대상이 바뀔 때까지 유지 |
| T3 | **확인 시트** (`.ny-sheet`) | 되돌릴 수 없거나 재화가 오가는 행동 (교환, 출금, 변경 버리기) | 사용자가 고를 때까지 |
| (오류) | 스낵바 error | 서버나 네트워크 실패 | 4초 + [다시 시도] |

## 2. 토큰
- 색: 바탕 크림 `#FFF6E6`, 글자 `#2A2238`, 보조 글자 `#6E6478`, 네이비 `#1E1A2B`
  - success 민트 `#8FE3C3` / 강조 글자 `#1F7158`
  - reward 앰버 `#FFC48A` / `#9A4F17`
  - info 하늘 `#9CC8FF` / `#2F5E9E`
  - error·경고 코랄 `#FF8A80`, 바탕 `#FFE3DF`, 글자 `#5A1E19`, 링크 `#B03A31`
- 대비 (WCAG): 본문 14.1:1, 보조 5.2:1, 경고 10.6:1, 버튼 15.8:1, 강조 글자 5.5~6.1:1 (모두 AA 이상)
- 모서리: 스낵바 20 / 칩 14 / 시트 28 / 아이콘 박스 14
- 글자 크기: 스낵바 제목 **15pt ExtraBold**, 보조 13pt, 칩 13.5pt Bold, 시트 제목 19pt, 시트 본문 14pt, 버튼 16pt
- 위치: 스낵바·배너는 헤더 바로 아래(top 115pt, 좌우 14pt). 시트는 아래, 고양이(cat-sleeping-nodrool)가 위 가장자리에서 빼꼼
- 모션: 들어올 때 420ms, 아래로 떨어지며 살짝 튕김(overshoot 6pt), 나갈 때 220ms 위로 페이드. 보상은 sfx-reward-coin, 오류는 haptic warning
- 접근성: T1·T1+는 `aria-live="polite"` (role=status), 오류와 T2는 `assertive` (role=alert), T3는 `role=dialog aria-modal`이고 포커스를 시트 안에 가둬요. 모션 줄이기 설정이면 튕김·슬라이드 대신 150ms 페이드. 지속 시간은 시스템 설정 배율을 따르고, 손가락이 올라가 있으면 타이머 멈춤

## 3. 문구 규칙
- 해요체, 1줄 제목은 16자 안팎. 숫자는 `<b>`로 강조.
- 경고는 **이유 + 다음 행동**: "방에 자리가 없어요 · 서랍에 넣기", "오늘 출금 한도를 다 썼어요 · 내일 0시에 다시 받을 수 있어요"
- 탓하지 않기 ("잘못", "실패했습니다" 금지). 오류: "저장하지 못했어요 · 네트워크를 확인하고 다시 눌러 주세요"
- 이모지는 축하 배너에서만 1개.

## 4. 큐
- 화면에는 **1개만** 보여요. 나머지는 순서대로 기다려요 (최대 3개, 넘치면 오래된 info부터 버림).
- 같은 key는 합쳐요: 냥코인 +1이 연속으로 오면 "냥코인 **3개** 받았어요"로 숫자만 갱신하고 타이머를 다시 시작해요.
- 우선순위: error > celebrate > reward > success > info. 시트가 열려 있으면 T1은 시트가 닫힐 때까지 기다려요.
- 보상이 2개 이상 동시에 생기면 스낵바 여러 개 대신 축하 배너 1개로 보여 줘요.

## 5. 기존 토스트 대체 표
| 화면/상황 | 예전 | 새로 | 문구 |
|---|---|---|---|
| 뽑기: 새 카드 | 리빌 상단 토스트 | 리빌 화면 안 카드(그대로) + 도감 이동 버튼 | (draw-reveal 문구 유지) |
| 뽑기: 중복 카드 | 중복 칩 | T1 info | 이미 만난 고양이예요 · 메뉴 › 중복 카드 교환에서 바꿀 수 있어요 |
| 뽑기: 광고 실패·취소 | 토스트 | T1 error | 광고를 끝까지 보지 못했어요 · 뽑기권은 그대로예요 |
| 도감: 보상 1개 받기 | 토스트 | T1 reward (key=ncoin, 합치기) | 냥코인 **1개** + 20P 받았어요 |
| 도감: 모두 받기 | 토스트 | T1+ celebrate | 보상 {n}개를 받았어요 · +{c} 냥코인 +{p}P |
| 도감: 세트·그룹 완성 | 축하 시트 | 축하 시트 유지 + 받은 뒤 T1+ | {품종} 세트 완성! 🎉 |
| 도감: 잠긴 칸 탭 | 토스트 | T2 칩 (칸 옆, 1.8초 뒤 자동으로 사라짐 예외) | 아직 못 만난 고양이예요 |
| 도감 이탈 시 남은 보상 | 없음 | T1 info + 액션 | 더 받을 보상이 **{n}개** 있어요 [보러 가기] |
| 냥코인 10개 처음 달성 | 토스트 | T1 reward + 액션 | 냥코인 10개! 토스포인트로 바꿀 수 있어요 [보상함] |
| 출금 확인 | 시트 | T3 | 토스포인트 {n}원을 받을까요? / 받은 포인트는 냥코인으로 되돌릴 수 없어요 [취소][받기] |
| 출금 완료 | 완료 화면 | 완료 화면 유지 + T1 success | 토스포인트 **{n}원**을 받았어요 |
| 출금 한도·잔액 부족 | 버튼 비활성 | T2 칩 (지갑 안) | 오늘 출금 한도를 다 썼어요 · 내일 0시에 다시 받을 수 있어요 / 10냥코인부터 받을 수 있어요 · {k}개 더 모으면 돼요 |
| 출금 실패 | 기록에만 표시 | T1 error | 보내지 못해 냥코인을 돌려드렸어요 |
| 중복 교환 | 확인 없이 바로 | T3 → T1 reward | 중복 카드 {n}장을 바꿀까요? → 포인트 **+{p}** 받았어요 |
| 방: 저장 | 토스트 | T1 success | 방을 저장했어요 |
| 방: 놓을 수 없음·자리 없음·같은 벽지 | 빨간 표시만 | T2 칩 (미리보기 옆) | 다른 가구와 겹쳐요 / 방에 자리가 없어요 · 서랍에 넣기 / 이미 같은 벽지가 깔려 있어요 · 다른 벽지 보기 |
| 방: 편집 취소 (변경 있음) | 없음 | T3 | 바꾼 내용을 버릴까요? [계속 꾸미기][버리기] |
| 방: 아이템 구매 | 토스트 | T1 success | {아이템}을 서랍에 넣었어요 [놓으러 가기] |
| 방: 포인트 부족 | 토스트 | T2 칩 (구매 버튼 위) | 포인트가 {k} 모자라요 · 출석·포인트 받기로 모아요 |
| 출석 체크 | 토스트 | T1 reward / 7일차는 T1+ | 출석 선물 도착! 발바닥 **30P** / 출석 7일 달성! 🎉 |
| 뽑기권 구매 | 토스트 | T1 success | 확률업 뽑기권을 샀어요 · 보유 **{n}/3** |
| 뽑기권 한도·보유 초과 | 토스트 | T2 칩 | 이번 주 구매 한도를 다 썼어요 · 월요일 0시에 다시 살 수 있어요 / 뽑기권은 3장까지 가질 수 있어요 |
| 네트워크·서버 오류 (공통) | 토스트 | T1 error + [다시 시도] | 연결이 잠시 끊겼어요 · 다시 시도해 주세요 |
