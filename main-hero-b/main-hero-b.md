## zip에 들어 있는 그림

모두 `public/assets/main/mainscreen-assets/` 로 들어갑니다. 크기는 1550×1944(승인된 그림의 2배)이고, 투명 WebP입니다.

- `hero-b-idle.webp` — 평소 모습. 달 + 고양이 + 손 안의 카드 + 꼬리 + 스티커 테두리 + 반짝임이 한 장에 들어 있습니다
- `hero-b-blink.webp` — idle과 같은 그림, 눈만 감은 전체 프레임
- `hero-b-blink-overlay.webp` — 눈 부분만 있는 투명 레이어. 깜빡임을 이 오버레이로 구현해도 됩니다
- `hero-b-empty.webp` — 오늘 카드를 다 뽑았을 때. 같은 달에 앉아 있고 손은 비어 있습니다
- `hero-b-sparkle.webp` — 작은 네 꼭짓점 별. 주변에 몇 개 놓고 천천히 깜빡이게 하세요
- `hero-b-layout.json` — 캔버스 크기, 눈 위치, 손 안 카드의 네 모서리(`cardQuad`), 반짝임 자리, 권장 CSS 크기(가로 약 270px). 좌표는 **2배 캔버스**(`canvas`)와 1배(`canvas1x`)가 모두 있습니다. 화면에 놓을 때는 실제 표시 너비에 맞춰 비율로 쓰세요

권장 구현: **idle 한 장을 메인 캐릭터로 쓰고**, 깜빡임·반짝임·카드 건네기만 그 위에 얹으세요. 달·몸·꼬리를 억지로 쪼개지 마세요. 달과 고양이는 같이 떠야 합니다.

## 평소 모습과 움직임

`src/screens/HomeScreen.tsx` 의 스테이지(`.main-cat-stage`) 안에서, 잠자는 고양이·침·꼬리·카드 덱 대신 새 히어로를 그리세요.

1. **기본 그림**은 `hero-b-idle.webp` 한 장입니다. 가로를 약 260~280 CSS px 로 두고, 비율은 그림 그대로(1550×1944) 유지하세요. `hero-b-layout.json` 의 `cssSuggest` 를 참고하세요. 화면 가운데, 날짜 줄 아래·뽑기 버튼 위, 시안 `01-home.png` 과 같은 자리에 두세요. 왼쪽 확률업 버튼·말풍선과 겹쳐도 됩니다. 지금처럼 확률업이 왼쪽 위에 얹히게 하세요.
2. **둥실 떠요.** 지금 `.main-float` 처럼 달과 고양이 전체가 천천히 위아래로 떠요(약 3.6초, 12px 안팎). 꼬리도 같이 움직이므로, 전체가 살짝 살랑이는 느낌이 납니다. 달을 고양이 없이 따로 떠오르게 하지 마세요.
3. **눈을 깜빡여요.** 3~4초에 한 번, 120~180ms 동안 `hero-b-blink.webp` 로 바꾸거나 `hero-b-blink-overlay.webp` 를 눈 자리에 얹으세요. 두 그림은 idle과 같은 캔버스라 위치가 맞습니다. 뽑기 동작 중에는 깜빡임을 잠시 멈춰도 됩니다.
4. **반짝임.** `hero-b-sparkle.webp` 를 `hero-b-layout.json` 의 `sparkles` 자리(특히 `outer-left`, `outer-right`. 달에 이미 그려진 별은 `paintedInIdle: true` 입니다)에 놓고, 투명도를 서로 다른 박자로 천천히 깜빡이게 하세요. 이미 그림에 있는 달 위 별과 겹쳐도, 바깥 두 개는 꼭 넣어 주세요.
5. **zzz와 침은 없앱니다.** 고양이가 더 이상 자지 않습니다. `.main-zzz`, `.main-drool` 과 관련 애니메이션을 스테이지에서 제거하세요.
6. **움직임 줄이기**(메뉴의 움직임 줄임, `.main-screen.is-reduce`): 둥실, 깜빡임, 반짝임, 건네기를 모두 멈추고 idle(또는 empty) 정지 화면만 보여 주세요. 지금처럼 OS `prefers-reduced-motion` 이 아니라 앱 안의 `.is-reduce` 만 따르면 됩니다.
7. 터치 영역(`.main-cat-hit` 또는 같은 역할)은 달과 고양이 전체를 덮게 하세요. `alt` / `aria-label` 에서 「잠자는 고양이」를 빼세요. 평소에는 「톡해서 오늘의 카드 받기」, 다 뽑았을 때는 지금처럼 「오늘은 이미 뽑았어요」 정도가 좋습니다.

## 화면을 누르면 (카드 건네기 + 뒤집기)

지금 코드는 터치 시 `waking` + `flipping` 을 켜고, `FLIP_MS`(180ms) + `SETTLE_MS`(240ms) 뒤에 `onDraw()` 를 부릅니다. **이 콜백과 광고·잠금 흐름은 그대로** 두세요.

새 동작:
1. 고양이가 **카드를 앞으로 건넵니다.** `public/assets/main/card-facedown.png` 를 손 안 카드 자리(`hero-b-layout.json` 의 `cardQuad` / `cardCss`)에 맞춰 올리고, 180~240ms 동안 살짝 커지며 시청자 쪽으로 다가오게 하세요. 손 안의 idle 그림 카드를 이 레이어가 덮으면 됩니다. 카드 뒷면은 반드시 기존 `card-facedown.png` 입니다.
2. 그 다음 **지금과 같은 뒤집기**(`rotateY`, 지금 `main-deck-flip` 또는 같은 느낌, 약 180ms)를 그 카드에 적용하세요.
3. 뒤집어지고 잠시 가라앉은 뒤 **지금과 같이** `onDraw()` 를 호출하세요. 건네기 시간만큼 타이머를 조금 늘려도 됩니다. `onDraw` 를 빼거나, 광고·확률업·한 번 더 뽑기 흐름을 바꾸지 마세요.
4. 이미 깨어나거나 뒤집히는 중이면 지금처럼 다시 누르지 못하게 하세요. `is-reduce` 이면 건네기·뒤집기 애니메이션을 생략하고 바로 `onDraw()` 에 가깝게 이어가도 됩니다.
5. 손 뒤에 깔리던 옛 3장 덱 표시는 없애도 됩니다. 남은 장수는 아래 알약(점 + 「오늘 N장…」)이 그대로 보여 줍니다. 첫 뽑기 전에 카드에 반짝임을 달던 `showSparkle` 은, 있다면 건네는 그 카드에 옮겨 주세요.
