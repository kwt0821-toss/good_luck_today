# 친구 초대 선물 — 시안 메모 (프롬프트 아님)

## 토스 쪽 사정 (2026-11-19 확인)
- 예전 "공유 리워드"(contactsViral / Promotion.openContactsInvite)는 2026-10-23에 끝났어요. 쓰면 안 돼요.
- 새 "바이럴 SDK"(Viral.getCampaign / share / track)는 SDK 3.3.0부터 들어 있지만(우리 앱 3.7.0), 캠페인 만드는 법·친구 판별 규칙 문서가 아직 없어요. 토스가 주는 보상 캠페인이면 비즈 월렛 예산(최소 5만 원)이 들 수 있어요.
- 그래서 우리 서버(Supabase 무료)로 직접 만들고, 선물은 앱 안 재화(젤리·뽑기권)로만 줘요. 냥코인(현금성)은 주지 않아요.

## 누가 불렀는지 아는 방법
1. 초대하는 사람: 서버가 그 사람만의 초대 코드(예: K7Q2MX)를 만들어 줘요.
2. Share.createLink({ path: "intoss://lucky-cat?invite=K7Q2MX", ogImageUrl }) 로 토스 링크를 만들고 Share.sendMessage로 보내요. (공유 창이 안 열리면 복사)
3. 친구가 링크를 누르면 토스 → 행운냥이 열리고, Environment.initialURL 안의 invite 값을 읽어요. (방 사진·프로모션 진입이 이미 같은 방식을 써요)
4. 친구가 첫 카드를 뽑으면 앱이 wallet 함수에 알려요. 서버가 아래 조건을 확인하고 두 사람 모두에게 지급해요.

## 막는 규칙
- 처음 시작한 친구만: 친구 계정이 처음 생긴 지 72시간 안, 예전에 행운냥을 한 적이 없어야 해요.
- 자기 자신 초대 안 돼요(같은 토스 계정 키면 거절).
- 친구는 평생 한 번만 초대받은 걸로 칠 수 있어요.
- 초대한 사람은 한 달 10명(economy.json 제안값 maxPerMonth 10), 하루 3명까지.
- 첫 카드 기록(첫 카드 젤리 기록)이 서버에 있어야 지급.
- 같은 지급은 한 번만(키: invite:<친구>:inviter / invite:<친구>:invitee).

## 선물(제안)
- 둘 다 똑같이: 젤리 150 + 확률업 뽑기권 1장
  - 젤리 150 ≈ 광고 젤리 하루 최대(100)의 1.5배, 뽑기권은 상점가 젤리 200
  - 뽑기권이 3장 꽉 차 있으면 젤리 200으로 대신 줘요(출석 7일차와 같은 규칙)
- 한 사람이 한 달에 받을 수 있는 최대: 젤리 1,500 + 뽑기권 10장(보관 최대 3장)

## 서버 작업 (다음 단계, 아직 안 만듦)
- 표 2개: invite_codes(user, code), invites(code, inviter, invitee 고유, status joined/rewarded, 시각)
- wallet 함수에 4가지 동작: 코드 받기, 초대 수락, 첫 카드 후 지급, 내 초대 현황
- 초대한 사람 선물은 앱을 열 때 받아요(푸시 없음)

## 조심할 점
- ogImageUrl(링크 그림)은 토스 Android 5.240.0 / iOS 5.239.0 이상만. 그 아래는 링크만 보여요.
- 토스 앱이 없는 친구는 설치 뒤 링크 정보가 사라질 수 있어요 → 처음 3일 안에는 "초대 코드 입력" 칸을 둘지 정해야 해요.
- 링크에 붙인 ?invite= 값이 실제 기기에서 그대로 넘어오는지 출시 전에 꼭 확인해야 해요(문서 예시는 있음).

## (추가 결정) 초대 코드 입력 칸 — 07-code-input.png
- 언제: 처음 시작하고 72시간(3일) 동안만. 서버 invite_status 의 canEnterCode / enterUntil 로만 정해요(폰 시계 안 씀).
- 어디: ① 친구 초대 창 맨 위 카드 "초대 코드가 있나요?" + "N일 남음" ② 메뉴 "친구 초대" 줄 오른쪽 "초대 코드 입력 · N일" + 빨간 점.
- 입력: 6자리(영문 대문자+숫자, 대소문자 구분 없음), [입력] 버튼. 비어 있으면 버튼 흐리게.
- 성공: 초록 카드 "초대 코드를 등록했어요!" / "첫 카드를 뽑으면 나도 친구도 이 선물을 받아요" + 젤리 150 · 확률업 뽑기권 1장.
- 오류(빨간 글씨, 칸 테두리 빨강):
  - 잘못된 코드: "없는 초대 코드예요. 친구에게 받은 코드를 다시 확인해 주세요."
  - 이미 초대받음: "이미 초대 코드를 등록했어요. 초대 선물은 한 번만 받을 수 있어요."
  - 내 코드: "내 초대 코드는 넣을 수 없어요. 친구에게 받은 코드를 넣어 주세요."
- 모든 사람에게 "내 초대 코드 K7Q3MX [코드 복사]" 줄이 생겨요(링크를 못 받은 친구에게 말로 알려 줄 수 있게). 초대 메시지에도 코드가 들어가요.
- 진행 줄 이름은 "이번 달 초대한 친구 n / 10명"(한도가 초대 연결 수 기준이라서)으로 바꿨어요.
