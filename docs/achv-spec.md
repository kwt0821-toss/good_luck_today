# 칭호(업적) UI 스펙 v2

설정: `achievements.json` 1.1 · 배지: `/assets/achv/badges/{id}.svg`

## 진입
- 별도 업적 메뉴 없음.
- 메인 `CAT.` 로고 아래, 방꾸미기 `MY ROOM.` 아래에 `#title-ribbon`.
- 리본: 배지 16px + 장착 칭호 + `›`. 받을 칭호 있으면 빨간 점.
- 칭호 없으면 점선 리본: `칭호 없음 · 새내기 집사 받기`.

## 바텀시트
- 탭: 전체 / 수집 / 뽑기 / 출석 / 방꾸미기 / 교환.
- 4열 그리드. 받을 수 있으면 민트 글로우 + 빨간 점(탭에도 점).
- 장착: `장착` 태그. 잠김: 회색이지만 이름 표시.

## 상세
- 큰 배지, 상태 칩, 이름, 조건, 진행바 `n/목표`.
- 계열(series)이면 단계 그래프(예: 1/10/30/60/90).
- 보상(냥코인·P). CTA: `[보상 받기]` / `[달기]` / 비활성 `진행 중 · n개 남았어요`.

## 수령
- `POST /achievements/claim` — 서버 검증, `requestId` 멱등.
- 축하 시트 + 냥 알림(냥코인·P). 해당 칭호·탭·리본 빨간 점 해제.
