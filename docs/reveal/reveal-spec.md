# 카드 크게 보기 (card reveal) — spec 2.0
기존 draw-reveal 1.0(타임라인·미리 받아 두기·멱등 drawId)을 이어받고, 카드를 화면 가득 크게 보여주는 전용 오버레이예요.

## 레이아웃 (기기 하드코딩 없음)
- `#card-reveal`: 토스 내비 아래 남은 영역 전체(flex column, `height:100%`, 하단 `env(safe-area-inset-bottom)`). 배경은 밤하늘 그라데이션 + 별, 뒤 화면은 보이지 않아요.
- 순서: 상단 행(냥 알림 pill + ✕) → `.stage`(flex:1) → 정보(이름·등급·NEW/중복 줄·힌트) → 버튼 2개.
- 카드: `height:100%; max-width:82%; aspect-ratio:900/1400`. 즉 가로 82%(80–84% 범위)가 기본이고, 세로가 짧은 기기에선 높이에 맞춰 줄어요. 둥근 모서리 22px.
- 버튼: 왼쪽 [한 장 더 뽑기 · 광고 · 남은 n회](외곽선), 오른쪽 [도감에서 보기](크림, 주 버튼). 남은 횟수 0이면 왼쪽은 '내일 또 만나요' 비활성.

## 연출
- 등장: 뒷면 → **900° / 1000 ms 회전 뒤집기**(rotateY, ease-out-cubic, perspective 1100px), 끝에서 scale 1.04→1.
- 글로우(`--g`, `--go`): 1–3★ 크림 #FFF6E6 약하게(.35–.45), 4★ 민트 #8FE3C3(.7), 5★ 골드 #FFD36B(.8), 밈 레몬 #FFE680, 캐릭터 라벤더 #C7B0FF, 레전드 골드 #F5D27A(1.0) + 레이 회전 + 샤인 스윕. 글로우·레이는 숨쉬듯 펄스(±4%).
- NEW 배지: 카드 오른쪽 위 코랄, 8° 기울임, 회전 끝난 뒤 pop.
- 중복: NEW 대신 정보 아래 칩 `x{보유수} 중복 · +{dupPaw}P로 바꿀 수 있어요`(전환은 도감에서).
- 광고 뽑기면 상단 pill 냥 알림 "카드를 뽑아 냥코인x1이 지급되었습니다." (뒤집기 끝난 뒤 slide-down, 2.6 s 뒤 사라짐). 무료·뽑기권 뽑기는 표시 안 함.
- 카드 톡: 앞/뒤 뒤집기(0.45 s) — 뒷면은 품종 정보 카드(card-back-*).
- 화면 아무 곳 톡(카드·버튼 제외): 연출을 건너뛰고 최종 상태로.
- reduced motion: 회전 대신 250 ms 크로스페이드.

## 닫기
✕, Android 뒤로가기, Esc 키 → 메인 뽑기 화면으로(카드는 이미 도감에 등록됨). [도감에서 보기] → 도감의 해당 카드 위치로 스크롤 + 강조.

## 데이터
서버 `POST /draw` 결과(cardId, grade, isNew, dupCount, dupPaw, ncoinGranted, images, remain)는 **지급 완료 상태**로 받아요. 오버레이는 결과를 보여주기만 하고 아무것도 지급하지 않아요.
