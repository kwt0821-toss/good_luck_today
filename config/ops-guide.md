# 럭키캣 운영 설정 가이드 (ops-config 1.1)

모든 숫자는 **서버 설정**이에요. 클라이언트는 값을 하드코딩하지 않고 서버에서 받아 써요. `_proposal: true`가 붙은 값은 아직 확정 전인 제안값이에요.

## 파일
| 파일 | 내용 |
|---|---|
| `economy.json` | **단일 소스.** 포인트 획득처(광고 10×10/일, 새 카드 +20, 중복 전환 10/30/60/150, 세트·전체 완성 보상), 토스 지급(1인 최대 417원), 뽑기 규칙(일반 3 + 확률업 1, 생애 첫 뽑기 무료), 제안 확률표, 코지 포인트·레벨 표, 상점 가격대, 방 해금, 이벤트, 어뷰징 방지 |
| `prices.json` | 방 아이템·타일 144개 전부의 가격, 코지 포인트, 등급, 플래그(`starterPlaced`, `starterDrawer`, `attendanceOnly`, `attendance:*`, `roomUnlockGift:*`, `roomDefault`, `limited`). 출석 한정 아이템 14개는 `source:"attendance"`, `price:null`, `purchasable:false`, `inShop:false`. id는 `room-assets-v6/items.json`, `room-assets-themes/items-themes.json` 기준이에요 |
| `starter.json` | 첫 방 배치(캣베드+히어로 고양이, 플로어 램프, 화분, 발바닥 러그, 아치 창문, 카드 액자, 기본 바닥·벽지), 서랍 4개, 시작 300포인트, 출석 규칙(`attendance`: 1주차 출석 한정 아이템 7개 → 주간 반복 → 30·100일 기념, 리셋 없음) |
| `tutorial.json` | 4단계 코치마크(대상 요소 id, 해요체 문구, 건너뛰기 규칙) + 2~6일차 '새 기능' 말풍선 일정 |
| `LuckyCat-economy.xlsx` | 기획 검토용 표. 노란 칸이 입력값이에요. 하루 수입을 바꾸면 '며칠 모으면'이 다시 계산돼요. eCPM은 비워 두었어요(앱인토스 대시보드 값을 입력) |

## 핵심 결정
- **코지 포인트**: 보유 아이템 1개당 등급별 점수(작은 소품 4 · 일반 가구 10 · 큰/대표 25 · 벽 꾸미기 6 · 벽지/바닥 8 · 레전드 60). 레벨 기준은 0/100/130/165/**200**(Lv.5)/225/250/**280**(Lv.8)/330/400이에요.
- **시뮬레이션**(활성 유저: 광고 8회, 뽑기 4회, 하루 최대 3개 구매, 300명 중앙값): Lv.5는 12일차, Lv.8은 28일차예요. 카페는 포인트를 모으느라 21일차쯤 해금돼요. 30일차 기준 도감 67장, 토스 지급 83원이에요.
- **가격**: 등급 범위 안에서 크기·존재감에 맞췄어요. 테마 대표 가구는 카페 6개, 온실 6개예요. 방 기본 타일은 0원(해금 시 지급)이에요. 레전드급 아이템은 아직 카탈로그에 없어요(규칙만 정의). 크리스마스 트리·선물 상자는 겨울 한정이에요.
- **방 해금 선물**: 카페는 카페 테이블·하트 의자·칠판 스탠드·메뉴 보드, 온실은 화이트 티테이블·튤립 화분·물뿌리개·행잉 바스켓이에요.
- **손익분기**: 30일 1인 토스 지급 83원, 광고 12회/일 기준으로 평균 eCPM 약 231원이면 손익분기예요(xlsx '보상·토스 지급' B23). 실제 eCPM을 넣으면 순이익이 계산돼요.

## 운영 체크
1. 토스 지급은 토스 계정당 보상 id별 1회예요. 서버에서 검증하고 `tossUserKey + rewardId`로 멱등 처리해요.
2. 광고 보상(뽑기·포인트)은 광고 완료 콜백을 받은 뒤에만 줘요. 뽑기 결과는 서버에서 정해요.
3. 주말 2배는 광고 포인트에만 적용해요.
4. 카드팩을 추가하면 도감 수와 최대 토스 지급(417원)을 다시 계산하고, economy.json을 함께 고쳐요.
5. 매일 볼 지표: D1/D7, 광고 시청/DAU, 광고 수익/유저, 토스 지급/유저, 도감 완성률, 포인트 발행−소비.

## 출석 (1.1에서 바뀜)
- **누적 출석일 기준, 리셋 없음.** 하루 1회(KST 00:00 기준) 출석하면 `attendanceDays`가 1 늘어요. 빠진 날이 있어도 다음 출석이 다음 일차예요.
- **1주차(1~7일, 처음 한 번)**: 출석 한정 아이템 7개. 달빛 냥이 선인장 → 출석 도장 달력 → 핑크 별 수면등 → 밤하늘 가랜드 → 달빛 지구본 → 벚꽃 금붕어 어항 → **달밤 캣타워**.
- **8일차부터 주간 반복**: 1~6일차 10 / 10 / 15 / 15 / 20 / 20 포인트(주 90). 7일차는 `day7.mode`로 정해요. 기본값 `alternate`는 홀수 주기에 **출석 선물 상자**(출석 한정 5종 중 아직 없는 것 랜덤, 다 모으면 100포인트), 짝수 주기에 **확률업 뽑기권 1장**(광고 없이 확률업 1회, 하루 한도와 별개, 최대 3장 보관)을 줘요.
- **누적 기념**: 30일 → 30일 골드 하트 네온 + 30일 배지, 100일 → 100일 별밤 벽등 + 100일 배지. 그날 출석 보상과 별개로 줘요. 목록은 `milestones`에 추가하면 돼요.
- **출석 한정**: 출석 아이템은 상점·서랍 기본 지급·방 해금 선물·이벤트·상자 외 보상 풀 어디에도 넣지 않아요. 서버가 지급 경로(출석 API)만 허용해요. 상점/서랍 UI에는 "출석 한정" 태그를 붙여요.
- **교체**: 기존 1주차 선물(냥이 선인장, 발바닥 달력, 별 수면등, 발바닥 가랜드, 지구본, 금붕어 어항, 캣타워)은 상점 아이템이라 출석에서 빼고, 같은 아트의 색 변형(att_*)으로 바꿨어요. 원본 7개는 상점 아이템으로 그대로 남아요.
- 아트: `attendance-items/` (items-attendance.json, items/, tiles/, badge-att-30.svg, badge-att-100.svg).
