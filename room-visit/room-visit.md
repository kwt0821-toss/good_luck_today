# Cursor 프롬프트 — 방 구경 가기 (행운냥)

아래 전체를 Cursor에 붙여 넣으세요. **앱 코드만** 바꾸세요. 서버(표·wallet 함수)는 `room-visit-server.zip` 으로 따로 준비되어 있고, 원따이님이 대시보드에서 이미 SQL 실행·Deploy 한 뒤여야 합니다. 저장소 안에 `supabase/functions` 나 SQL 을 새로 만들지 마세요.

이 작업은 **편지함 프롬프트(`mailbox.md`)를 이미 실행한 뒤**를 전제로 합니다. 방 사진 서버(`room-photo`)도 이미 붙어 있어야 합니다.

규칙:
- 뒤로가기 버튼(`DevBackButton` 등)을 새로 만들지 마세요. 창은 닫기(X)·창 밖 탭·기기 뒤로가기로 닫습니다.
- `appName`은 `lucky-cat` 그대로 유지하세요.
- 화면 문구에 **포인트 / 토스포인트 / 출금 / 인출 / "P"** 를 쓰지 마세요. 재화 이름은 **발바닥 젤리**(짧게 **젤리**)와 **냥코인**입니다.
- 새 환경 변수·유료 서비스·새 패키지를 추가하지 마세요. 서버 호출은 기존 `wallet` 함수와, 방 사진을 남길 때만 기존 `room-photo` 함수를 씁니다.
- 하트 젤리 금액은 **전부 서버가** 정합니다. 앱이 로컬 잔액에 +5 하지 마세요. `jellyBalance` 가 오면 `rememberJelly` 로 맞추세요.
- 다른 사람의 실명·토스 이름·내부 번호(hash)는 화면에 쓰지 마세요. 보이는 이름은 **닉네임만**입니다.

**다른 프롬프트와 파일이 겹칠 수 있습니다.** `src/screens/RoomScreen.tsx`, `RoomScreen.css`, `src/lib/serverSave.ts`, `src/lib/serverWallet.ts` 를 만질 때, 이미 있는 사진 찍기·꾸미기·저장·편지함·초대 동작을 **되돌리거나 덮어쓰지 마세요.** 방 구경 입구와 새 화면만 더하세요.

## 결정 (그대로 따르세요)

1. **방 공개를 켜야만** 오늘의 방·인기 방·친구 탭에 내 방이 보여요. **기본값은 꺼짐**입니다. 저장만 했다고 올라가지 않아요.
2. **닉네임 기능을 새로 만듭니다.** 실명·토스 이름은 가져오거나 보여 주지 마세요.
   - 2~8글자, 한글·영문·숫자만. 공백·이모티콘·특수문자 불가. 숫자만으로 된 이름 불가.
   - 같은 이름을 다른 사람도 쓸 수 있어요(중복 허용).
   - 한국 시간 기준 하루에 한 번만 바꿀 수 있어요. 처음 정하는 것은 언제든 가능해요.
   - 욕설·「운영자」「관리자」 같은 사칭은 서버가 거절합니다. 거절되면 짧게 안내만 하세요.
   - 닉네임을 아직 안 정한 사람이 방 공개를 켜려고 하면, **공개를 켜기 전에 닉네임부터** 정하게 하세요.
3. 하트는 **같은 방에 한 번만**, **내 방에는 못 눌러요.** 하루에 처음 하트를 눌렀을 때만 발바닥 젤리 5개를 받아요. 안내 문구는 시안처럼 「오늘 첫 하트예요! 발바닥 젤리 5개를 받았어요」.

그 밖에:
- 구경 목록·방문 화면은 시안처럼 **전체 화면**입니다. 메뉴 시트 안에 구겨 넣지 마세요. 닫기 X, 뒤로가기 버튼 없음. 닫으면 내 방꾸미기 화면으로 돌아와요.
- 「다음 방」은 지금 보고 있는 탭 목록의 다음 방으로 바로 들어가게 하세요. 목록 끝이면 처음 방으로 돌아거나, 더 없으면 버튼을 숨기거나 비활성하세요.
- 가구는 만질 수 없어요. 방문 화면에는 시안처럼 「가구는 만질 수 없어요. 구경만 해요.」를 보여 주세요.

## 서버 API (wallet 함수, 이미 준비됨)

`src/lib/serverWallet.ts` 에 아래 함수를 편지함과 같은 패턴으로 추가하세요. `postWallet` 로 부릅니다.

1. `visit_status` — `{}`
   - 응답: `{ ok, roomId, nickname, hasNickname, isPublic, photoLive, hasLayout, canPublish, likeJelly: 5, photoDays: 30, canChangeNickname, rules }`
   - 저장 전에도 동작합니다. `allowMissing` 은 false 로. (저장이 있는 계정은 토큰과 함께 부르세요.)
2. `visit_set_nickname` — `{ nickname }`
   - 응답: status 와 같은 모양
   - 실패 `error`: `nickname_invalid`, `nickname_denied`, `nickname_day_limit`, `blocked`, `bad_input`
3. `visit_set_public` — `{ isPublic: true|false }`
   - 켜기 전에 앱이 방 사진을 `room-photo` 에 올려 두세요. 서버는 창고에 최근 30일 사진이 있는지, 저장본에 방 배치가 있는지, 닉네임이 있는지만 확인합니다.
   - 실패 `error`: `need_nickname`, `need_photo`, `need_room`, `blocked`, `bad_input`
   - 끄기는 사진이 없어도 됩니다.
4. `visit_sync_layout` — `{}`
   - 공개 중일 때 방을 저장한 뒤 한 번 부르세요. 서버가 저장본에서 배치를 다시 읽습니다. 큰 JSON 을 wallet 본문에 보내지 마세요.
5. `visit_list` — `{ tab: "friends"|"today"|"popular" }`
   - 응답: `{ ok, tab, today, items: [{ roomId, nickname, likes, photoUrl, likedByMe }] }`
   - 저장 전에도 목록은 볼 수 있게 해 두었습니다. 내 방은 목록에 안 나옵니다. `roomId` 만 쓰고 hash 는 화면에 쓰지 마세요.
6. `visit_get` — `{ roomId }`
   - 응답: `{ ok, roomId, nickname, likes, photoUrl, likedByMe, isMine, layout }`
   - `layout` 은 `{ currentRoomId, cozyLevel, shadowsEnabled, room }` 입니다. `room` 을 `RoomWorld` 에 넣어 그리세요.
   - 실패 `error`: `not_found`, `bad_input`
7. `visit_like` — `{ roomId }`
   - 응답: `{ ok, already, roomId, likes, likedByMe, jellyGranted, jelly, jellyBalance, likeJelly }`
   - 같은 방을 다시 눌러도 성공으로 돌아오되 `already:true`, `jelly` 는 0 입니다. 두 번 지급하면 안 됩니다.
   - `jellyBalance` 가 오면 그걸 쓰고, 로컬에 +5 하지 마세요.
   - 실패 `error`: `self_like`, `not_found`, `blocked`, `bad_input`

방 사진 올리기(`room-photo` 함수):

- 본문: `{ action: "upload", hash, mime: "image/jpeg", imageBase64 }` (data URL 접두사는 떼도 됩니다)
- 헤더: 기존 wallet 과 같이 apikey, `x-save-token`
- 하루 5장 한도가 있습니다. 한도에 걸리면 공개는 켜지 말고, 「오늘은 방 사진을 더 남길 수 없어요. 내일 다시 시도해 주세요」처럼 짧게 알려 주세요.
- `room-photo-share-fix` 작업이 이미 있다면 그 올리기 함수를 재사용하세요. 없으면 작은 도우미만 추가하세요.

## 화면

### 방꾸미기 입구 (시안 01 왼쪽)

- 보기 모드에서 「사진 찍기」 왼쪽에 「방 구경 가기」 알약 단추. 호박색 테두리, 어두운 반투명 배경, 크림/호박 글씨. 시안처럼 살짝 빛나는 테두리여도 됩니다.
- 누르면 구경 목록 전체 화면을 엽니다.

### 구경 목록 (시안 01 오른쪽)

- 제목 위 작은 글씨 「방꾸미기」, 큰 제목 「방 구경.」(마침표는 호박색), 설명 「다른 고양이의 방에 놀러 가요」, 오른쪽 위 닫기 X.
- 탭: **친구 / 오늘의 방 / 인기 방**. 선택된 탭 아래 호박색 밑줄. 친구 탭 안내 「초대로 이어진 친구의 방이에요」. 다른 탭도 짧은 안내를 두어도 됩니다(예: 「오늘 만난 방이에요」, 「좋아요를 많이 받은 방이에요」).
- 카드 2열: 방 사진, 닉네임, 하트 수. 사진을 누르면 그 방으로 들어갑니다. `photoUrl` 이 있으면 그걸 쓰고, 없으면 빈 밤하늘 칸만 두세요.
- 아래 작은 글씨 「닫기를 누르면 내 방으로 돌아와요」.
- 목록이 비면 짧게 「아직 공개한 친구가 없어요」 / 「오늘의 방이 아직 없어요」 / 「아직 인기 방이 없어요」처럼 알려 주세요.

목록 화면 안에 **「내 방 공개 설정」** 입구를 하나 두세요. 시안을 가리지 않게, 제목 근처나 아래쪽에 작은 글씨/단추로 두세요. 이 창에서:
- 지금 닉네임, 바꿀 칸, 저장
- **내 방 공개** 켜기/끄기 (기본 꺼짐)
- 공개를 켜는데 닉네임이 없으면 닉네임 칸을 먼저 보여 주고, 정한 뒤에만 공개가 켜지게 하세요.
- 공개를 켤 때는 지금 방을 사진으로 남겨 `room-photo` 에 올린 다음 `visit_set_public({ isPublic:true })` 을 부르세요. 사진이나 배치가 없으면 서버 오류 그대로 「방 사진을 남기지 못했어요」 / 「아직 꾸민 방이 없어요」처럼 쉽게 알려 주세요.
- 사진이 30일이 지나 `photoLive` 가 false 이면, 공개가 켜져 있어도 「방 사진이 만료되어 목록에서 내려갔어요. 사진을 다시 남기면 올라가요」라고 짧게 알려 주고, 다시 사진을 남길 수 있게 해 주세요.

### 방문 화면 (시안 02, 확대는 03)

- 위: 「방 구경」, 「(닉네임)님의 방」(닉네임은 호박색), 닫기 X. 내 방의 MY ROOM 제목·아늑함 숫자·방 전환 칩·꾸미기/저장/초기화 바는 보여 주지 마세요.
- 가운데: 그 사람의 `layout` 으로 그린 아이소메트릭 방. 가구를 눌러도 움직이지 않아요.
- 아래: 「가구는 만질 수 없어요. 구경만 해요.」
- 하트를 눌러 오늘 첫 보상을 받으면, 시안처럼 어두운 알약 안내 「오늘 첫 하트예요! 발바닥 젤리 5개를 받았어요」(「발바닥 젤리 5개」는 호박색).
- 하단 바: 왼쪽 채워진 하트와 좋아요 수, 오른쪽 호박색 「다음 방 ›」.
- 이미 하트를 누른 방은 하트가 채워진 채로, 다시 눌러도 젤리를 또 주지 마세요.
